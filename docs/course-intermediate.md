# QM Intermediate: Course overview {#intermediate-course}

QM Intermediate builds on the probability, inference, and R skills from QM
Basic. The central question changes from “What does this sample show?” to
“How is an outcome related to several variables at the same time?”

<div class="outcomes">
<span class="label">By the end of QM Intermediate, you can</span>
<ul>
<li>formulate simple and multiple-regression questions from E&BI problems;</li>
<li>fit, diagnose, and interpret linear regression models in R;</li>
<li>distinguish a coefficient, fitted value, residual, and uncertainty interval;</li>
<li>interpret tests against zero, \(R^2\), and F-tests for model usefulness;</li>
<li>use dummy predictors, interactions, and polynomial terms;</li>
<li>explain how controls change an estimate without automatically making it causal;</li>
<li>read the central regression evidence in a business or management paper.</li>
</ul>
</div>

## How this course connects

Expectation and variance become the foundations for regression coefficients
and residual variation. Covariance and correlation motivate linear
relationships, while the inference tools from Basic return when we quantify
uncertainty around model estimates.

The Shark Tank data continue as the main shared example. Additional datasets
are not required for the core sequence.

## Course sequence

| Chapter | Central question |
|---|---|
| Lecture 1 | What line best summarises the relationship between two variables? |
| Lecture 2 | How uncertain is a coefficient, and when is its SE trustworthy? |
| Lecture 3 | How much variation does the model explain, and is it useful overall? |
| Tutorial 1 | Can you fit, diagnose, and communicate a simple regression? |
| Lecture 4 | How do we interpret one predictor while holding others fixed? |
| Lecture 5 | How do categories enter a model, and are terms jointly useful? |
| Lecture 6 | When does a slope depend on another variable or change across \(x\)? |
| Tutorial 2 | Can you build and defend a multiple-regression specification? |
| Mock exam | Can you integrate the complete course in a 100-point assessment? |

External video explanations come from Stanford's
[Statistical Learning series](https://www.youtube.com/playlist?list=PLoROMvodv4rOzrYsAxzQyHb8n_RWNuS1e).
The supporting print text is James, Witten, Hastie, and Tibshirani,
*An Introduction to Statistical Learning*, 2nd edition, especially Chapter 3.
Each lecture chapter contains the definitions, notation, examples, and
practice required for this course.

## Tutorials and assessment

Two tutorials—one after Lecture 3 and one after Lecture 6—combine
interpretation with hands-on R work. They prepare you to work with data in R
during the TestVision assessment. If an R workflow has become rusty, return to
the [R Refresher](#r-refresher) or the earlier
[Programming for E&BI](https://walshc.github.io/ebi-prog/) textbook.

After completing Tutorial 2, attempt the [QM Intermediate Mock
Exam](#intermediate-mock-exam) in R under timed conditions.
