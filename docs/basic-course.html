QM Basic: Course overview

QM Basic introduces the language and logic needed to turn data into careful evidence. We begin with data summaries and visualisation, build probability models, and then use sampling distributions to understand confidence intervals and two-sided tests against zero.

By the end of QM Basic, you can
  • identify observational units, variables, samples, populations, and selection limits;
  • summarise and visualise quantitative and categorical data in R;
  • work with events, random variables, distributions, expectation, variance, covariance, and correlation;
  • use uniform, normal, and t models with their stated conditions;
  • explain sampling variability, standard errors, confidence intervals, and two-sided tests against zero;
  • interpret supplied R output with correct units, uncertainty, scope, and causal limits.

How to read every graph

Use the same sequence whenever a graph appears:

  1. Read the horizontal axis: identify the variable, its units, and the shown range.
  2. Read the vertical axis: decide whether it shows a count, proportion, percentage, density, outcome, residual, or fitted value.
  3. Decode each mark: determine what one point, bar, line, shaded area, or interval represents.
  4. Check the scale and displayed sample: look for zooming, unequal panel scales, omitted observations, and whether an axis starts at zero when that matters.
  5. Describe the visible pattern before interpreting it. Then state the population, design, and causal limits.

The graph-specific paragraphs in the lectures apply this sequence directly.

Tutorials and assessment

Four tutorials provide guided exam preparation. Bring your attempted after-class questions and use the cumulative QM Basic Formula Sheet during each tutorial. The complete sheet is attached to the closed-book written exam.

The QM Basic Mock Exam contains 100 points and uses the same calculation, supplied-output interpretation, conditions, and scope language required in the course.
