# QM Basic: Course overview {#basic-course}

QM Basic introduces the language and logic needed to turn data into careful
evidence. We begin with data summaries and visualisation, build probability
models, and then use sampling distributions to understand confidence intervals
and two-sided tests against zero.

<div class="outcomes">
<span class="label">By the end of QM Basic, you can</span>
<ul>
<li>identify observational units, variables, samples, populations, and selection limits;</li>
<li>summarise and visualise quantitative and categorical data in R;</li>
<li>work with events, random variables, distributions, expectation, variance, covariance, and correlation;</li>
<li>use uniform, normal, and t models with their stated conditions;</li>
<li>explain sampling variability, standard errors, confidence intervals, and two-sided tests against zero;</li>
<li>interpret supplied R output with correct units, uncertainty, scope, and causal limits.</li>
</ul>
</div>

## How to read every graph

Use the same sequence whenever a graph appears:

1. Read the horizontal axis: identify the variable, its units, and the shown
   range.
2. Read the vertical axis: decide whether it shows a count, proportion,
   percentage, density, outcome, residual, or fitted value.
3. Decode each mark: determine what one point, bar, line, shaded area, or
   interval represents.
4. Check the scale and displayed sample: look for zooming, unequal panel
   scales, omitted observations, and whether an axis starts at zero when that
   matters.
5. Describe the visible pattern before interpreting it. Then state the
   population, design, and causal limits.

The graph-specific paragraphs in the lectures apply this sequence directly.
