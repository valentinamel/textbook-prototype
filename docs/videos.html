External Video Guide

This page is a map to external videos used in the course. Every clip has one of three purposes:

  • Required before class: watch it before the lecture. These clips are also listed in that lecture’s Video preparation box.
  • Review when needed: the clip explains a concept taught in class. Use it after the lecture, after an absence, or before practice if the concept is not yet secure.
  • Optional extension: the clip adds another example or more depth. It is not required.

Only clips labelled Required before class are compulsory preparation. Review and extension clips do not add examinable content; the scope and notation in this textbook remain authoritative. Basic primarily uses MIT OpenCourseWare pages, which include videos and transcripts. Intermediate uses Stanford’s Statistical Learning series. The complete collections are the MIT probability playlist and the Stanford Statistical Learning playlist.

Supplementary probability reading

MIT OpenCourseWare provides Bertsekas and Tsitsiklis’s Introduction to Probability: Selected Textbook Summary Material. The official page includes the PDF download. This is a reference, not a required 77-page reading. Read only a section that a lecture explicitly assigns or that you need for review.

Basic Lecture 1: Introduction to Data Analysis

No external video is assigned. Preparation is listed in the lecture chapter.

Basic Lecture 2: Probability Foundations and Random Variables

Required before class

  • 01.2 Sample Space — outcomes, sample spaces, and events.
  • 01.4 Probability Axioms — non-negativity, normalisation, and additivity.
  • 05.2 Definition of Random Variables — a random variable as a function from outcomes to numbers.

Review when needed

  • 01.3 Sample Space Examples — another pass through outcomes and events.
  • 01.5 Simple Properties of Probabilities — complement and addition rules derived from the axioms.
  • 01.10 Interpretations and Uses of Probabilities — how the meaning of a probability depends on the model.

Optional extension

  • 01.7 A Discrete Example — a worked discrete probability model.

Basic Lecture 3: Discrete Distributions and Expectation

Required before class

  • 05.3 Probability Mass Functions — point probabilities and the normalisation rule.
  • 08.7 Cumulative Distribution Functions — accumulated probability and the discrete CDF.
  • 05.8 Expectation — expectation as a probability-weighted average.

Review when needed

  • 05.4 Bernoulli and Indicator Random Variables — coding an event as 1 and its complement as 0.

Basic Lecture 4: Variance, Conditioning, and Belief Updating

Required before class

  • 06.2 Variance — expected squared distance from the mean.
  • 02.2 Conditional Probabilities — restricting and rescaling the reference class.
  • 02.8 Bayes’ Rule — reversing a condition using base rates and likelihoods.

Review when needed

  • 02.6 The Multiplication Rule — expressing a joint probability through a conditional probability.
  • 02.7 Total Probability Theorem — combining conditional probabilities across a partition.

Optional extension

  • 02.3 A Die Roll Example — a worked conditioning example.

Basic Lecture 5: Joint Random Variables, Covariance, and Correlation

Required before class

  • 06.7 Joint PMFs and the Expected Value Rule — joint probabilities and expectations involving two variables.
  • 12.5 Covariance — covariance as an expected product of deviations.
  • 12.8 The Correlation Coefficient — standardising covariance.

Review when needed

  • 03.3 Independence of Two Events — the conditional and product definitions of event independence.
  • 07.2 Conditional PMFs — a conditional distribution within a fixed value of another variable.
  • 07.4 Independence of Random Variables — factorisation of the joint PMF.
  • 12.10 Interpreting the Correlation Coefficient — what correlation does and does not describe.

Optional extension

  • 12.6 Covariance Properties — additional algebraic properties of covariance.

Basic Lecture 6: Continuous Distributions and the Normal Model

Required before class

  • 08.2 Probability Density Functions — density, area, and interval probability.
  • 05.5 Uniform Random Variables — constant density over an interval.
  • 08.8 Normal Random Variables — normal shape and parameters.

Review when needed

  • 08.9 Calculation of Normal Probabilities — standardisation and normal interval probabilities.

Basic Lecture 7: Samples, Parameters, and Estimators

Required before class

  • 20.3 The Sample Mean and Some Terminology — parameters, estimators, estimates, and the sample mean.

Basic Lecture 8: Sampling Distributions and the CLT

Required before class

  • 18.4 The Weak Law of Large Numbers — convergence of a sample mean.
  • 19.2 The Central Limit Theorem — the normal approximation for standardised sums and means.

Basic Lecture 9: Confidence Intervals and Tests Against Zero

Required before class

  • 20.5 Confidence Intervals — repeated-sampling coverage.
  • 20.6 Confidence Intervals for the Estimation of the Mean — the known-variance mean interval.
  • 20.7 Confidence Intervals for the Mean When the Variance Is Unknown — estimating the SE and using a t reference distribution.
  • Introduction to Hypothesis Testing — the null model, a two-sided alternative, and the p-value.

Basic Lecture 10: Hypothesis Testing, Errors, and Power

Required before class

  • Introduction to Hypothesis Testing — review the null model, two-sided alternatives, and p-values.
  • Examples Identifying Type I and Type II Errors — decision errors in context.
