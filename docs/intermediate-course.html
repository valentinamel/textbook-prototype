QM Intermediate: Course overview

QM Intermediate builds on the probability, inference, and R skills from QM Basic. The central question changes from “What does this sample show?” to “How is an outcome related to several variables at the same time?”

By the end of QM Intermediate, you can
  • formulate simple and multiple-regression questions from E&BI problems;
  • fit, diagnose, and interpret linear regression models in R;
  • distinguish a coefficient, fitted value, residual, and uncertainty interval;
  • interpret tests against zero, \(R^2\), and F-tests for model usefulness;
  • use dummy predictors, interactions, and polynomial terms;
  • explain how controls change an estimate without automatically making it causal;
  • read the central regression evidence in a business or management paper.

How this course connects

Expectation and variance become the foundations for regression coefficients and residual variation. Covariance and correlation motivate linear relationships, while the inference tools from Basic return when we quantify uncertainty around model estimates.

The Shark Tank data continue as the main shared example. Additional datasets are not required for the core sequence.

External video explanations come from Stanford’s Statistical Learning series. The supporting print text is James, Witten, Hastie, and Tibshirani, An Introduction to Statistical Learning, 2nd edition, especially Chapter 3. For a more formal treatment, consult Nieuwenhuis, Statistical Methods for Business and Economics, especially Chapters 19–22. Each lecture chapter contains the definitions, notation, examples, and practice required for this course.

Tutorials and assessment

Two tutorials—one after Lecture 3 and one after Lecture 6—combine interpretation with hands-on R work. They prepare you to work with data in R during the TestVision assessment. If an R workflow has become rusty, return to the R Refresher or the earlier Programming for E&BI textbook.

Use the cumulative QM Intermediate Code Sheet throughout the tutorials and when preparing for the final exam. After completing Tutorial 2, attempt the QM Intermediate Mock Exam in R under timed conditions.
